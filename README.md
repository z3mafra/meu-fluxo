# Meu Fluxo

Protótipo v0.1 de um app pessoal para organizar tarefas de trabalho, casa e lazer.

## O que dá para fazer

- Capturar tarefas na Entrada.
- Organizar tarefas em Entrada, Hoje, Próximas e Aguardando.
- Filtrar por Trabalho, Casa e Lazer.
- Definir prazo, concluir, editar ou excluir tarefas.

## Como executar

É necessário ter Node.js instalado. No terminal, dentro da pasta do projeto:

```sh
npm start
